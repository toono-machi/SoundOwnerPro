# Sound Owner Pro

GitHub Pages 対応のブラウザ音声エディターです。サーバー側処理やビルドは不要です。ライブラリのプロジェクト履歴はブラウザの IndexedDB に保存します。

## 公開

1. ZIPファイルを展開します。
2. `index.html`、`css/`、`js/`、`assets/` をGitHubリポジトリのルートに配置します。
3. GitHubの **Settings → Pages → Deploy from a branch → main / (root)** を選びます。
4. 表示されたPagesのURLから利用します。

ローカル環境で `index.html` を開いて動作確認することもできます（機能によりブラウザの権限設定が必要）。Chrome/Edge最新版を推奨します。

## 主な機能

- TXTまたは貼り付け台本の読み込み、3桁番号とキャラクター名の自動抽出
- キャラクター管理、キャラクター別トラック、効果音・環境音・BGMトラック
- WAV/MP3素材の読み込み、台本番号に応じた自動仕分けとサブタブ管理
- メディアボックス素材行のゴミ箱で不要な素材を直接削除（配置済みの同素材クリップも削除、確認あり）
- 台本読み込み・貼り付けボタンは指定の専用PNGアイコンを使用。見出し横の音声追加ボタンは廃止
- 音声の試聴、シーク位置への配置、波形表示、タイムライン上での移動・トリミング・分割
- トラックごとのミュート・ソロ、マスターと各トラックの音量調整
- 5バンドEQ、HP/LPフィルター、残響、コンプレッサー、リミッターと音声加工プリセット
- トラック種類別再生モード、プロジェクトJSON保存・読み込み（音声本体を含む）
- 左メニューのホーム／ライブラリ／マーカー／プロジェクト画面。ライブラリは保存・読み込んだプロジェクトをブラウザ内に記録し一覧から復元（再ダウンロード・履歴削除も可能）
- 13章構成の操作マニュアル（上部「ヘルプ」または左メニュー「マニュアル」からアプリ内に表示）
- エフェクトの設定画面を「EQ／リバーブ／コンプレッサー／リミッター」の4種類のタブで切り替え
- エフェクトごとに独立したプリセット管理（別のエフェクトの設定は変更せず適用）
- ユーザープリセットを4種類に分類して専用JSONに書き出し／読み込み（旧プリセットJSONも読み込み可能）
- 全体・キャラクターのみ・キャラクターごと・選択キャラ・カテゴリごと・視聴用を書き出し
- 通常マーカー位置での分割と3桁連番、指定した各区間名を付けた書き出し
- 視聴用開始／終了マーカー、フェードイン・フェードアウト指定
- 44.1 kHz / 16-bit ステレオWAV、MP3（192 kbps）。複数ファイルはZIPにまとめる

## MP3形式での書き出し

MP3エンコードのみ、ブラウザ側で `lamejs` v1.2.1 をCDNから初回読み込みします。インターネット接続が必要です。CDNにアクセスできない場合はWAV形式を選択してください。読み込み・編集・再生・WAV書き出しは外部接続不要です。

## 制限・注意

- 現行版は1カテゴリ1トラックを基本とし、キャラクタートラックは1キャラクターにつき1つ作ります。
- オーディオエフェクトはトラック単位、音量・フェードはクリップ単位でも調整できます。
- 入力音声はWeb Audio APIのデコードに対応したWAV/MP3を想定しています。特殊な符号化の音声は読み込めない場合があります。
- 再生およびオーディオの書き出し処理はブラウザのCPU・メモリを使用します。長尺作品は分割することを推奨します。
- ZIPは標準の非圧縮ZIP形式で作成します。一般的な解凍ソフトで展開できます。
- ブラウザのページを閉じると未保存のプロジェクト状態は消えるため、随時「保存」を行ってください。
- 「保存」を押すと音声込みJSONをダウンロードし、同一ブラウザ内のライブラリ（IndexedDB）にも履歴の登録を試みます。ブラウザ保存容量の制限などで登録できないことがあります。その場合もJSONのダウンロードは継続されます。
- 以前のバージョンでダウンロードしたJSONは、更新版で一度「開く」から読み込むとライブラリに登録されます。古いダウンロードファイルをブラウザが自動検出することはありません。
- ライブラリはローカル保存です。端末やブラウザ間で同期されず、サイトデータを削除すると消えることがあります。ダウンロード済みJSONを必ずバックアップしてください。
- ブラウザのキャッシュやローカルストレージを消去するとユーザープリセットが消えることがあります。専用JSONとしてバックアップしてください。

## 操作

`Space` 再生/一時停止、`M` 通常マーカー追加、`S` 選択クリップをシーク位置で分割、`Delete` 選択クリップ削除、`Ctrl+S` JSON保存。

## 同梱素材

提供されたロゴ・ミモザ・プリン・下部装飾のPNGを `assets/` に組み込み済みです。

## エフェクトのプリセット（v1.1）

「音声プロパティ」タブのエフェクト行「設定 ›」を押すか、「エフェクト」タブで「イコライザー／リバーブ／コンプレッサー／リミッター」を選びます。上部のプリセット欄には現在選択している種類のプリセットだけが表示されます。「適用」を押すと現在の種類の設定だけが変わります。ON/OFFは「有効」で切り替えます。

「＋ このエフェクトを登録」ボタンで現在の種類の設定をプリセットとして保存します。ブラウザ内に保存したプリセットは別のプロジェクトでも利用できます。JSON保存は`groups.eq`、`groups.reverb`、`groups.compressor`、`groups.limiter`で種類ごとにまとめます。初期版のプリセットJSONや旧ブラウザ保存済みプリセットも自動で分類して取り込みます。

- マーカー・プロジェクトも左メニューから専用の管理画面を表示。
- ヘルプは別タブを開かず、エディター内のマニュアル画面に切り替わります。左の目次から全13章を移動できます。
